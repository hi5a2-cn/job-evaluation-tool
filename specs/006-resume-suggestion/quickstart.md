## 一、自动化测试验证命令

所有测试均在本地隔离环境中运行，不发起外部网络请求、不需要真实 API Key、不操作真实数据库目录。

### 1. 后端自动化测试 (Python / Pytest)

```bash
# 运行后端全量测试套件（严格冻结依赖）
uv run --frozen pytest

# 重点测试本功能新增与受影响的模块
uv run --frozen pytest tests/unit/test_resume.py tests/unit/test_prompt_v6.py tests/unit/test_staleness_v6.py tests/api/test_judgements_resume.py
```

#### 覆盖重点：
- `test_resume.py`：配置文件读取、格式校验、合法方向数 $<2$ 容错告警、`key -> file_name` 解析；
- `test_prompt_v6.py`：`v6` 提示词拼接、说明段追加、外发内容不含文件名与姓名断言、`parse_facts` 校验与理由截断；
- `test_staleness_v6.py`：基准 `STALE_METHOD_BASELINE = "v5"` 验证，断言 `v5` 与 `v6` 均不为 `method_changed`，`v4` 为 `method_changed`；
- `test_judgements_resume.py`：`to_api` 装配、数据库存取与迁移、Worker 写入两列、规则判断两列为 `NULL`。

### 2. 插件端单元测试 (Node.js Test Runner)

## 二、真实环境手动验证清单 (Q1–Q10)

在完成代码编写并通过自动化测试后，在真实 Chrome 浏览器中加载插件并连接本机 Jet 服务（`jet serve`），按以下顺序核验功能：

| 序号 | 验证场景 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|
| **Q1** | **运营类岗位生成建议** | 已配置 3 份简历，打开 BOSS 搜索列表 | 打开一个 AI 运营类岗位详情，等待判断完成 | 详情卡片与侧边栏显示"建议投：简历A.pdf"；鼠标悬停显示符合职责的一句话理由。 |
| **Q2** | **数据类岗位生成建议** | 同上 | 打开一个数据分析 / 技术支持类岗位详情，等待判断完成 | 详情卡片与侧边栏显示"建议投：简历B.pdf"；悬停显示理由。 |
| **Q3** | **生命科学类岗位生成建议** | 同上 | 打开一个宠物医疗或动物实验类岗位详情，等待判断完成 | 详情卡片与侧边栏显示"建议投：简历C.pdf"；悬停显示理由。 |
| **Q4** | **结论为不建议投时屏蔽** | 同上 | 打开一个房地产或保险等变相销售岗位（结论为 `skip`） | 结论显示"不建议投"，卡片与侧边栏**绝对不显示**任何简历建议行。 |
| **Q5** | **规则直接排除岗位屏蔽** | 同上 | 打开一个命中国家/城市底线排除的岗位（规则直接排除） | 结论显示规则排除，卡片与侧边栏**绝对不显示**简历建议。 |
| **Q6** | **已有 v5 判断不标过时** | 库中有升级前生成的 v5 判断数据 | 启动升级后的服务，打开该岗位详情 | 该岗位**不显示**"可能过时"，后台**不自动发起**大模型重判，调用额度不增加，卡片保持原样。 |
| **Q7** | **旧判断手动重判升级** | 在 Q6 的 v5 旧判断卡片上 | 点击"重新判断"按钮 | 后台发起 v6 判断，完成后卡片刷新，出现"建议投：<文件名>"与理由。 |
| **Q8** | **HR 索要简历突出提示** | 处于 BOSS 聊天页，某会话中 HR 发送了简历请求卡片 | 打开该会话，查看右侧侧边栏当前岗位 | 侧边栏卡片顶部以醒目橙色框突出展示："HR 在要简历，建议投：<对应文件名>"及理由。 |
| **Q9** | **HR 要简历但岗位无建议** | 处于 BOSS 聊天页，会话有简历请求，但岗位为 v5 判断 | 打开该会话，查看侧边栏 | 侧边栏不突出展示建议，显示文案："点重新判断可获得简历建议"；点击重新判断后生效。 |
| **Q10** | **切换会话即时清理** | 当前会话已展示 Q8 的醒目简历提示 | 在 BOSS 聊天列表点击切换到另一个没有简历请求的会话 | 醒目提示立即消失，侧边栏恢复为新会话岗位的常规展示，不残留上一会话的提示。 |
| **Q11** | **外发内容安全性核查** | 本机开启抓包或查看 DeepSeek 请求日志 | 触发一次 v6 判断 | 核对发往模型的请求 JSON：提示词仅含 3 个方向的代号与中文描述，**100% 不含文件名（.pdf）与求职者姓名（（用户姓名））**。 |
| **Q12** | **配置文件缺失容错** | 临时重命名 `resume_directions.json` 为 `.bak` | 触发一次新岗位判断 | 判断正常完成，日志记录一次警告，卡片与侧边栏正常显示结论与理由，无简历建议，不报错。 |
