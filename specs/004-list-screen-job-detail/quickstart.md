# Quickstart: 验证列表页规则粗筛 + 独立职位页被动读取

**Feature**: `004-list-screen-job-detail`

## 前提

- `jet serve` 在后台运行（由 Claude 重启），插件已在 `chrome://extensions` 重新加载，BOSS 页面已刷新。
- 画像已设：最低月薪（例如 8K）、不接受条件（例如"销售"）、不去的城市（任选一个）。
- 在设置页「从严行业」里勾选要从严的行业（006 起改为个人勾选、默认都不勾；不勾就不会出现「粗筛：高风险行业」，Q1 无法验证）。

## 自动测试

```bash
uv run --frozen pytest
```

```bash
node --test extension/tests/*.test.js
```

预期全部通过；新增测试覆盖粗筛计算、行业匹配、`company_legal_name` 入库、独立职位页 DOM 读取、提示标记。

| Q3 | 找技能标签含"销售"但职位名不含的岗位 | 显示"命中不接受条件：销售" | FR-001、FR-002 |
